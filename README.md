# Second‑Price Auction HW
這是一個以「第二價格拍賣（Second Price Auction）」為題的作業／範例專案，使用 Python 與 Jupyter Notebook 撰寫。
專案目的在於模擬、比較、分析第二價格拍賣機制下的參與者出價行為與結果。

---

## 功能概要
- 模擬多名競標者在第二價格拍賣機制下進行出價。
- 計算拍賣過程中的關鍵指標，如最高出價、第二高出價、得標者與支付價格。
- 分析不同參與者策略（如：真實價值出價、加碼、保守出價）對拍賣結果的影響。
- 提供圖形化／報表化結果（在 Jupyter Notebook 中展示）以便解釋機制與結論。

## 模擬說明（範例）
- 假設有 N 位競標者，每位競標者有一個「真實價值」 v_i。
- 每位競標者依策略提出出價 b_i。
- 在第二價格拍賣中：
  - 出價最高者得標。
  - 得標者支付的是第二高出價，而非自己的出價。
- 模擬可重複多輪，記錄每輪出價、得標者、支付價格、以及得標者的利潤（真實價值 − 支付價格）。
- 最終可統計：平均得標價格、不同策略下的得標機率、參與者收益情況等。

---

## 為什麼選擇這個機制？
第二價格拍賣具有以下特點：
- 鼓勵競標者報出其「真實價值」作為出價，因為支付由第二高出價決定，理論上報價誠實是一個**優勢策略**。
- 有助於減少「過度競價」風險，並提升效率。
- 是學術與實務中經常被引用的拍賣機制，適合作為作業或研究範例。
